# Wyoming Soniox

Fast streaming **speech-to-text** and **text-to-speech** for Home Assistant Assist, powered by
[Soniox](https://soniox.com).

## Features

- Speech recognition that knows when you stopped talking: the transcript is ready right away, no waiting for
  Home Assistant's silence detection.
- Spoken answers that start while the assistant is still writing them.
- Russian and 60+ other languages; every voice speaks every language.
- Pay-as-you-go: about $0.12 per hour of recognized audio and $0.70 per hour of speech.

## Getting started

1. Create an API key at [console.soniox.com](https://console.soniox.com) with speech-to-text and text-to-speech
   permissions.
2. Enter it in the app configuration and start the app.
3. Confirm the discovered **Wyoming Protocol** integration and select **soniox** in your voice assistant.

Details are on the **Documentation** tab and in the
[project README](https://github.com/darkdarin/wyoming-soniox).
